📋 ОПИСАНИЕ НА ПРОЕКТА:
-----------------------
Това е прост, но функционален калкулатор, написан на Python.
Проектът демонстрира използването на класи, методи и управление
на историята на операциите.

🎯 ОСНОВНИ ФУНКЦИИ:
-------------------
✓ Събиране на числа
✓ Изваждане на числа
✓ Умножение на числа
✓ Деление на числа (с проверка за деление на нула)
✓ Преглед на текущия резултат
✓ Преглед на историята на операциите
✓ Нулиране на калкулатора
✓ Интерактивен потребителски интерфейс

📁 СТРУКТУРА НА ФАЙЛОВЕТЕ:
--------------------------
1. models.py
   - Съдържа класа Calculator
   - Определя методите за аритметични операции
   - Управлява резултатите и историята

2. main.py
   - Главното приложение
   - Интерактивно меню за потребителя
   - Обработване на входни данни и грешки

3. requirements.txt
   - Списък на необходимите библиотеки

4. readme.txt
   - Този файл с документация

💻 КАК ДА ИЗПОЛЗВАТЕ ПРОЕКТА:
-----------------------------

ИНСТАЛАЦИЯ:
1. Уверете се, че имате Python 3.7 или по-нова версия
2. Клонирайте проекта от GitHub
3. Отворете терминала в директорията на проекта

ПУСКАНЕ:
  python main.py

ИЗПОЛЗВАНЕ:
1. Изберете операция от менюто (1-8)
2. Въведете числата, които искате да обработите
3. Резултатът ще се покаже веднага
4. Можете да видите историята на всички операции

🔧 ТЕХНИЧЕСКИ ДЕТАЙЛИ:
---------------------

КЛАСА CALCULATOR:
- __init__(initial_value=0)
  Инициализира калкулатора с начална стойност

- add(number)
  Събира число към текущия резултат

- subtract(number)
  Изважда число от текущия резултат

- multiply(number)
  Умножава текущия резултат по число

- divide(number)
  Дели текущия резултат на число
  Хвърля ValueError при деление на нула

- get_result()
  Връща текущия резултат

- reset()
  Нулира калкулатора и историята

- get_history()
  Връща списък с всички операции
